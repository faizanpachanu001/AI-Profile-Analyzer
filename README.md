# AI-Profile-Analyzer
In this project, when a user answers a set of questions about themselves and how they feel to get a complete profile file that tell the issues about them and how they can fix it.
 AI Profile Analyzer

AI Profile Analyzer is a private self-reflection web experience designed to help users put their thoughts into words, recognize personal patterns, and identify areas for growth.

## Features

- Thoughtful self-reflection questionnaire
- Multiple-choice and free-text questions
- Progress tracking
- Skip questions when needed
- Personal reflection report
- Strength and growth insights
- Pattern recognition
- Gentle action plan
- Basic safety detection
- Responsive design for desktop and mobile
- Dark, calm, privacy-focused interface

## Tech Stack

- HTML
- CSS
- JavaScript
- Google Fonts
